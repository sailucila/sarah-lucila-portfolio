# Sarah Lucila Portfolio

A static portfolio with four pages and bundled images. No build step or external image service is required.

## GitHub Pages

Upload this folder's contents to a repository. In Settings > Pages, choose Deploy from a branch, main, and / (root). The homepage is index.html.

Keep assets/ beside the HTML files. Internal links use relative paths and work under a GitHub Pages repository URL.

## Before public launch

Review project screenshots for client information that should not be public. Add Sarah's preferred public contact or booking link. The site currently has no contact form or email destination. Publishing this site makes its image files accessible to visitors.

Original portfolio videos are not included. Experience and credentials are based on Sarah's supplied content.
